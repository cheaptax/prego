# Prego AI 주식평가 운영 가이드

## 제공 기능

- 기초잔고, 매수, 매도 거래 입력
- 이동평균법 기준 평균단가와 실현·미실현손익 계산
- 증권사간 입출고 기록과 증권사별 수량 검증
- 현재가 기준 종목별 포트폴리오 비중
- 기업행위가 반영된 수정주가 기준 역사적 최고가, 최고가 기준 평가손익, 최고가 대비 하락률
- 단일 종목 집중도와 고점 대비 낙폭 점검

## 데이터 저장 위치

- 개인 거래: `users/{uid}/stockTransactions/{transactionId}`
- 공용 시장가격 캐시: `stockMarketQuotes/{symbol}`

거래 API는 로그인한 회원의 UID 하위 데이터만 읽고 씁니다. 시장가격 캐시는 종목코드별 공용 데이터이며 개인 보유정보를 포함하지 않습니다.

## 운영 환경 변수

```env
STOCK_PORTFOLIO_ENABLED=true
KIS_APP_KEY=<한국투자증권 Open API App Key>
KIS_APP_SECRET=<한국투자증권 Open API App Secret>
```

세 값은 Vercel Project Settings > Environment Variables에 서버 전용 변수로 등록합니다. `NEXT_PUBLIC_` 접두어를 붙이지 않습니다.

## 활성화 절차

1. 한국투자증권 Open API에서 App Key와 App Secret을 발급합니다.
2. Preview 환경에 세 환경변수를 등록합니다.
3. `/mypage/investments`에서 기초잔고 한 건을 입력합니다.
4. `실제 주가 갱신`을 실행해 현재가와 역사적 최고가가 채워지는지 확인합니다.
5. 매수·매도·증권사간 이체를 각각 입력해 수량과 평균단가가 예상대로 유지되는지 확인합니다.
6. 검증 후 Production 환경에도 같은 변수를 등록하고 재배포합니다.

## 시세 연동 방식

- 현재가: 한국투자증권 국내주식 현재가 API
- 역사적 최고가: 수정주가 연간 봉으로 최고 연도를 찾은 뒤 해당 연도의 수정주가 일봉에서 정확한 최고가와 날짜를 확정
- API 토큰: 서버 메모리에 만료 시각과 함께 캐시
- 일부 종목 조회 실패: 성공한 종목만 갱신하고 실패한 종목은 기존 캐시를 유지

## 회계·평가 로직

- 매수 원가 = 수량 × 단가 + 수수료 + 세금
- 평균단가 = 누적 취득원가 ÷ 보유수량
- 매도 실현손익 = 매도대금 - 매도비용 - 매도수량 × 직전 평균단가
- 증권사간 이체는 전체 보유수량, 취득원가, 평균단가, 실현손익을 변경하지 않습니다.
- 현재 비중은 모든 보유 종목에 현재가가 존재할 때만 계산합니다.

## 주의사항

- 이 기능은 투자자문이나 수익 예측 기능이 아닙니다.
- 기업분할, 합병, 상장폐지 후 재상장 등 복잡한 기업행위는 공급자 수정주가를 우선 사용하되 예외 검증이 필요할 수 있습니다.
- 시장가격 캐시는 운영비와 호출 제한을 고려해 사용자 요청 시 갱신합니다. 향후 Vercel Cron으로 장 마감 후 일괄 갱신할 수 있습니다.
