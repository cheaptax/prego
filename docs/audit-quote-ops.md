# FY27 회계감사 견적 — 직원 운영 가이드

운영 주체: **주식회사 프리고** (민간 서비스). 농협중앙회 공식 서비스가 아닙니다.  
관리 화면: `/admin` → **Audit quotes** 탭 (기존 관리자 로그인/`requireAdmin` 권한 필요)

## 알림 설정

1. Slack Incoming Webhook 또는 호환 webhook URL 발급
2. Vercel/`.env.local`에 설정
   - `AUDIT_QUOTE_NOTIFY_WEBHOOK_URL`
   - (선택) `AUDIT_QUOTE_NOTIFY_INCLUDE_EMAIL=true` — 기본 비활성. 제목에는 이메일 미포함
   - (선택) `AUDIT_QUOTE_ADMIN_BASE_URL=https://your-domain`
3. 신규 접수는 Firestore 저장 후 비동기 알림. 알림 실패해도 고객 접수는 성공으로 유지
4. 실패/미설정 건은 `auditQuoteNotifications`에 기록되며, 상세 화면 **알림 재시도**로 재처리

알림 제목 형식: `신규 회계감사 견적 요청 · {publicReference}`

## 운영 절차

### 1. 신규 접수 확인
- Webhook 알림 또는 `/admin` → Audit quotes → 필터 `received`
- 미처리 건수(received)를 매일 확인

### 2. 중복·스팸·잘못된 이메일 처리
- 24시간 내 동일 캠페인·이메일은 시스템이 자동 중복 병합
- 명백한 스팸/오기는 상태를 `invalid`로 변경하고 사유를 내부 메모(담당자 필드/운영 노트)로 남김

### 3. 고객 최초 회신
아래 템플릿 사용. 금지문구 금지.

### 4. 필수 견적정보 수집
- 농협명, 결산/사업연도, 연결범위, 희망 일정, 특이사항 등
- 상태: `contacting` → `qualified` → `info_complete`

### 5. 고객의 후보·공유범위 확인
- 어떤 회계법인에 어떤 항목을 공유할지 고객 확인 후에만 전달

### 6. 회계법인의 수임·독립성 확인
- 프리고가 독립성을 “보장”하지 않음. 각 법인이 기준에 따라 확인

### 7. 동일 조건의 견적 요청 패킷 발송
- 상태 `quotes_requested`
- 동일 조건 패킷으로 2곳 이상 요청 (보장이 어려운 경우 고객 문구와 동일하게 표현)

### 8. 견적 수령과 누락 항목 보완
- `quoteCount`를 실제 수령 건수로 갱신
- 누락 시 법인에 보완 요청

### 9. 최소 2건 견적 전달
- 비교 가능한 형태로 고객 이메일 전달
- 상태 `delivered`

### 10. 선정 검토보고서 안내
- 내부 의사결정 참고자료이며 공식 인증/추천이 아님을 고지
- 상태 `report_delivered`

### 11. 계약·포인트 조건 확인
- 제휴/이벤트 요건이 확정된 경우에만 안내
- 포인트는 **우리 농협 법인 포인트**. 담당자 개인 지급 아님

### 12. 개인정보 보유기간 종료와 삭제
- 보유기간 정책에 따라 원문 이메일·접수 문서 삭제/익명화
- 삭제 전 관리자 이중 확인
- 상세 절차·승인 요건: `docs/audit-quote-release.md` (무단 운영 데이터 삭제 금지)

### 13. 직원 접근권한 부여·회수
- `/admin` Members → 운영자 계정으로만 부여
- 퇴사/역할 변경 시 즉시 회수

### 14. 월별 접근권한 검토
- 매월 운영자 목록·Audit log 점검

### 15. 이벤트 종료
- `AUDIT_QUOTE_EVENT_ENABLED=false` 또는 `AUDIT_QUOTE_ENDS_AT` 설정
- 잔여 `received`/`contacting` 건 종료 처리 후 `closed`

## 최초 고객 회신 템플릿

제목:
`[농협지원센터] 회계감사 견적 요청이 접수되었습니다.`

본문:

```
안녕하세요. 요청하신 회계감사 견적 비교를 진행하기 위해 몇 가지 필수정보를 확인하고자 합니다. 아래에서 편한 진행방식을 선택해 주세요.

1. 담당자와 짧게 통화하며 정보 정리
2. 온라인에서 직접 작성

아직 회계법인에 정보가 전달되지 않았으며, 견적 요청 전 공유 대상과 항목을 다시 확인해 드립니다.
```

## 직원 금지문구

- “여기가 무조건 제일 잘합니다.”
- “무조건 가장 싸게 됩니다.”
- “독립성 문제는 없습니다.”
- “감사의견도 잘 나올 겁니다.”
- 실제 권한 없이 “농협중앙회 공식 서비스입니다.”
- “포인트는 담당자 개인에게 지급됩니다.”

## 권한·감사

- 인증/관리자 권한 없는 사용자는 API·화면에서 조회·수정 불가 (`requireAdmin`)
- 목록: 이메일 마스킹 / 상세: 원문 이메일
- 상태·담당·견적수 변경 시 `auditLogs`에 이전값·새값 기록
- 동시 수정은 `expectedUpdatedAt` precondition으로 충돌 감지

## IAM 참고

서비스 계정은 Admin SDK 경로로만 intake/admin API가 Firestore에 접근합니다.  
클라이언트 규칙은 `auditQuote*` 컬렉션을 deny-all 합니다. 상세는 `docs/audit-quote-deploy.md`.
