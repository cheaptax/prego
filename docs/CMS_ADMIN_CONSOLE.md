# 콘텐츠 관리자 사용 안내

기준일: 2026-07-21  
주소: `/admin`

## 목적

콘텐츠 관리자는 개발 지식 없이 화면과 공통 영역의 운영 상태를 확인하고, 미게시 초안을 검토해 게시하기 위한 업무 화면이다. 회원 승인, 상담 답변과 포인트 업무는 `회원·상담 운영`에서 기존 기능을 그대로 사용한다.

## 접근 권한

- Firebase 로그인 정보에 관리자 권한이 확인된 계정만 접근할 수 있다.
- 로그인하지 않은 사용자는 로그인 화면으로 이동한다.
- 로그인했지만 관리자 권한이 없는 사용자는 권한 없음 안내를 본다.
- 목록 조회와 게시 요청은 서버에서도 관리자 권한을 다시 확인한다.

## 메뉴

1. **대시보드**: 편집 가능한 페이지, 미게시 초안, 최근 수정·게시와 검토 항목
2. **페이지 관리**: 화면 검색, 분류, 공개 범위, 게시 상태와 최종 수정 정보
3. **공통 영역**: 서비스 이름, 상단 메뉴, 하단 정보, 고객지원과 공통 안내
4. **디자인 설정**: 승인된 색상, 글자 크기, 간격, 모서리와 정렬의 현재 값
5. **이미지·파일**: 등록된 자료의 종류, 크기, 대체 설명과 사용 상태
6. **수정·게시 이력**: 관리자별 최근 초안 수정, 복원과 게시 기록

## 페이지 관리

- `편집`을 누르면 해당 화면의 전용 페이지 편집기로 이동한다.
- `미리보기`는 현재 접근 가능한 실제 화면을 새 창으로 연다.
- 게시 전 변경이 있을 때만 `게시` 버튼이 활성화된다.
- 게시 전 확인 창에서 영향받는 화면과 주소를 다시 안내한다.
- 게시 중 다른 관리자가 먼저 수정하면 덮어쓰지 않고 최신 상태 확인을 요청한다.

CMS 저장 내용이 없으면 안전한 코드 기본값으로 모든 화면과 공통 영역을 표시한다. 잘못된 게시본이나 초안은 그대로 사용하지 않고 대시보드의 확인 항목으로 안내한다.

## 기본 설정과 고급 정보

일반 화면에는 업무에 필요한 이름, 설명, 상태와 날짜만 표시한다. 초안·게시 번호와 같은 기술적 관리 정보는 화면 편집 준비 패널의 `고급 정보`를 펼쳤을 때만 표시한다.

직접 구조화 데이터나 화면 코드를 입력하는 칸은 제공하지 않는다. 디자인도 정해진 선택지로만 관리한다.

## 로딩·빈 화면·오류

- 최초 진입과 새로고침 중에는 준비 안내를 표시한다.
- 자료나 이력이 없으면 빈 화면 안내와 다음 행동을 설명한다.
- 서버 오류는 내부 오류문을 노출하지 않고 다시 불러오기 방법을 안내한다.
- 공개 화면은 관리자 콘솔 오류와 관계없이 기존 게시본 또는 코드 기본값으로 계속 동작한다.

## 현재 단계의 범위

페이지 편집기의 핵심 흐름이 연결되어 있다.

- 좌측 화면 영역 목록, 중앙 실시간 미리보기, 우측 선택 영역 설정
- 좁은 화면의 영역 목록·미리보기·편집 설정 탭 전환
- 제목·본문·안내·버튼·내부/외부 링크와 반복 항목 편집
- 섹션과 목록 항목 순서 끌기, 키보드 이동 버튼, 표시·숨김
- 목록 항목 추가·복제·복구 가능한 삭제와 복원
- 승인된 글꼴·글자 크기·굵기·줄 간격·정렬·색상·배경·여백·테두리·모서리·그림자
- PC·태블릿·모바일별 상세 크기, 줄 간격과 여백
- 이미지 추가·교체·화면에서 삭제, 대체 설명과 비율 설정
- 삭제한 이미지와 상단 메뉴는 초안에 보관되며 편집 화면에서 다시 복원
- 자동 초안 저장, 직접 저장, 실행 취소·다시 실행, 변경 비교
- 게시 전 검사, 게시 확인, 게시 이력과 이전 버전 초안 복원
- 다른 관리자의 동시 변경 시 버전 충돌 경고
- 비교 창에서 화면 전체 정보, 문구, 카드·목록 순서, 버튼·링크, 이미지와 디자인 변경 종류 표시
- 모든 CMS 확인 창에서 첫 조작 항목으로 초점 이동, Tab 초점 순환과 Esc 닫기 지원

메인 화면과 공통 영역의 실제 편집 흐름이 연결되어 있다.

- 메인 화면은 운영 화면과 같은 `Topbar`, `Hero`, `About`, `Expertise`, `Services`, `Process`, `CaseStudies`, `FAQ`, `Footer` 컴포넌트로 미리본다.
- `첫 화면`, `서비스 요약 수치`, `센터 소개`, `농협이 체감하는 가치`, `전문성 카드`, `지원 분야 전체 카드`, `상담 흐름 STEP 01~04`, `문의게시판 안내`, `자주 묻는 질문`이라는 업무용 이름을 사용한다.
- 서비스 이름·로고, 상단 메뉴·로그인/회원가입/상담 버튼, 하단 정보, 고객지원 플로팅 버튼은 페이지와 분리된 공통 초안으로 관리한다.
- 공통 영역도 자동 저장, 직접 저장, 변경 비교, 게시 이력, 이전 게시본의 새 초안 복원과 명시적 게시를 지원한다.
- 공통 영역 게시 확인에서는 영향을 받는 모든 화면을 안내한다.
- 메인 화면의 `화면 전체 설정`에서 꼭 필요한 경우에만 상단 또는 하단을 해당 화면에서 숨기는 명시적 페이지별 덮어쓰기를 사용할 수 있다.

FY27 회계감사 견적 화면의 실제 편집 흐름도 연결되어 있다.

- `/admin/pages/event.auditQuote`에서 공개 화면과 같은 `AuditQuoteEventPage`로 초안을 미리본다.
- 첫 화면, 견적 신청 영역, 제공 혜택, 진행 순서, FAQ, 운영 주체와 면책문구를 업무용 이름으로 편집한다.
- 입력 표시 이름·예시·도움말과 검증·처리 중·성공·오류 안내는 바꿀 수 있지만 내부 입력 이름, 제출 주소와 저장 키는 바꿀 수 없다.
- 개인정보 필수 동의 영역과 면책문구는 숨기거나 삭제할 수 없다. 문구를 바꾸면 경고하고 게시 이력에도 법적 문구 변경을 표시한다.
- 페이지·카드·신청 버튼 디자인은 승인된 선택지만 제공하며 임의 코드나 CSS는 입력하지 않는다.
- 상세 운영 방법과 보호 범위는 `docs/CMS_AUDIT_QUOTE.md`를 따른다.

## 전체 화면 편집 범위

`/admin`의 페이지 목록에는 홈, 로그인, 회원가입, 승인 대기, 이용약관, 개인정보처리방침, 상담 신청, 문의 게시판, FAQ, 고객지원, 회계감사 견적, 마이페이지, 문의 상세, 파트너 접근 안내, 콘텐츠 관리자, 회원·상담 운영, 페이지 없음 안내가 업무용 이름으로 표시된다.

- 계정 찾기 패널은 로그인 화면에서, 모바일 메뉴는 상단 메뉴 공통 영역에서 편집한다.
- 회원·관리자 전용 화면은 고정 fixture 미리보기를 사용하므로 실제 개인정보를 읽지 않는다.
- 미리보기의 인증, API 요청, 저장, 포인트 차감, 승인·거절과 게시 동작은 비활성화된다.
- 폼 표시 문구와 안전한 디자인만 바꿀 수 있으며 내부 field name, URL endpoint, Firestore key, 인증·권한과 계산식은 편집 항목에 나타나지 않는다.
- 이용약관, 개인정보처리방침, 회원가입 필수 동의와 문의 상세의 포인트성 안내는 필수 영역으로 보호한다. 법적 문구 변경은 경고와 게시 이력에 표시한다.
- `/partner`는 실제 partner 인증과 배정 ACL이 구현될 때까지 잠긴 접근 안내만 편집·게시한다.

## 페이지 편집기 사용 순서

1. 페이지 관리에서 `편집`을 누른다.
2. 왼쪽에서 화면 영역을 선택하거나 가운데 미리보기에서 원하는 영역을 누른다.
3. 오른쪽에서 문구, 버튼, 이미지와 디자인을 바꾼다.
4. 상단 저장 상태가 `초안 저장됨`인지 확인한다.
5. `비교`와 게시 전 경고를 확인한다.
6. `게시`에서 영향받는 화면 주소를 확인한 뒤 명시적으로 게시한다.

저장 실패 안내가 보이면 현재 입력은 브라우저 화면에 남아 있다. 필수 문구, 링크 주소와 고급 숫자 범위를 먼저 확인하고, 인터넷 연결을 확인한 뒤 `저장`을 다시 누른다. 충돌 안내가 보이면 다른 관리자의 변경을 덮어쓰지 말고 `최신 내용 다시 불러오기`로 확인한다.

이전 버전 복원은 즉시 고객 화면을 바꾸지 않는다. 선택한 게시 버전을 새 초안으로 만든 뒤 미리보기와 비교를 거쳐 다시 게시해야 한다.
이미지의 `화면에서 삭제하고 보관`을 선택해도 파일 참조는 초안과 이력에
남는다. 같은 위치의 `이미지 복원`으로 다시 표시할 수 있다.

## 공통 영역 편집 순서

1. `공통 영역`에서 `서비스 이름과 로고`, `상단 메뉴와 주요 버튼`, `하단 정보`, `고객지원` 중 하나의 `내용 편집`을 누른다.
2. 왼쪽에서 다른 공통 영역으로 이동하고, 가운데 실제 메인 화면에서 PC·태블릿·모바일 표시를 확인한다.
3. 오른쪽에서 업무용 문구와 링크를 편집한다. 상단 메뉴는 끌기 또는 이동 버튼으로 순서를 바꾼다.
4. 로고는 10MB 이하 JPG, PNG, WebP 또는 GIF를 사용하고 대체 설명을 확인한다.
5. `비교`와 `이력`을 확인한 뒤 `게시`한다.

공통 영역의 초안은 관리자 미리보기에서만 보인다. 저장만 하고 게시하지 않은 내용은 일반 고객에게 노출되지 않는다. 이전 버전을 복원해도 새 초안만 만들어지며, 다시 게시하기 전까지 공개 화면은 바뀌지 않는다.
